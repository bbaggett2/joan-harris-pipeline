# HU_AI_GE_Thumbnail_instructions.MD
**Brand:** Handwriting University (HU)
**Method:** AI-Generated Host (Gemini) + PIL Brand Layer (Two-Pass)
**Executor:** Claude Cowork (autonomous) — N8N-ready trigger slot
**Last Updated:** 2026-08-10

---

## 1. PURPOSE

This file is the complete, self-sufficient recipe for producing HU YouTube thumbnails where the host image is AI-generated by Gemini — NOT taken from a human screenshot. Claude reads this file, receives a trigger prompt, and completes the entire job through Slack delivery and approval without stalling.

Do not confuse this with `SOP_HU_IG_Screenshot_Torn_Paper_v2.md` (screenshot method). That method requires a human-provided video frame. This method does not.

---

## 2. WHEN TO USE THIS METHOD

Use this MD when:
- No approved human screenshot is available
- The video is new and no frame has been designated by Bart
- The trigger prompt arrives from N8N or directly from Bart via Slack/Claude

Use the screenshot method (`SOP_HU_IG_Screenshot_Torn_Paper_v2.md`) when:
- Bart has provided a specific video frame he wants used
- The video is a talking-head format where a real expression is critical

## 4. WHAT CLAUDE NEEDS TO START (INPUT VARIABLES)

Claude requires these variables before executing. They arrive in the trigger prompt — from Bart directly, or eventually from N8N:

| Variable | Description | Example |
|---|---|---|
| `VID_ID` | Video ID or slug | `0812` |
| `SLUG` | Short descriptor for file naming | `fear-of-judgment` |
| `HEADLINE` | Main text that appears on the thumbnail | `THEY CAN TELL` |
| `SUBHEAD` | Smaller supporting line (optional, can be empty) | `from this one stroke` |
| `EXPRESSION` | Bart's expression direction | `intense, knowing, serious` |
| `BACKGROUND` | Environment description | `dark navy psychological study, dimly lit` |
| `VISUAL_LEFT` | What appears on the left side of the frame | `handwriting trait card showing the fear-of-ridicule t-bar` |
| `TRAIT_CARD_PATH` | Path to the trait card image (if one exists) | `$REPO_ROOT/assets/trait-cards/fear-ridicule.jpg` |

If `TRAIT_CARD_PATH` is empty, omit the image from `--reference` and describe the visual element in text only in the prompt.

## 5. EXECUTION SEQUENCE

Claude executes all steps via Desktop Commander on Bart's Mac. Gemini API is not accessible from the cloud sandbox — all script calls go through Desktop Commander.

### STEP 1 — Confirm GitHub assets are present on Mac

```bash
ls $REPO_ROOT/assets/headshots/
ls $REPO_ROOT/scripts/
```

If missing, pull the repo:
```bash
cd $REPO_ROOT && git pull origin main
```

### STEP 2 — Build the Gemini prompt from the template

Use the 6-section formula below (Section 6). Fill in the variables from the trigger prompt. Save the completed prompt to a temp file:

```bash
cat > /tmp/thumbnail_prompt.txt << 'EOF'
[COMPLETED PROMPT GOES HERE]
EOF
```

### STEP 3 — Run Pass 1: Gemini generates person + background

```bash
cd $REPO_ROOT

python3 scripts/generate_thumbnail.py \
  --headshot assets/headshots/Bart-serious-clear-bluesuit.png \
  --reference assets/headshots/BartBaggett72whitebackgroundB16A5244blue_B.jpg \
  --reference assets/headshots/B16A5236_revised_bart_red_smile.jpg \
  --reference assets/logos/HU_logo_navy_quill.png \
  [--reference $TRAIT_CARD_PATH if provided] \
  --prompt "$(cat /tmp/thumbnail_prompt.txt)" \
  --aspect 16:9 \
  --output outputs/$VID_ID-$SLUG-raw-16x9.png

python3 scripts/generate_thumbnail.py \
  --headshot assets/headshots/Bart-serious-clear-bluesuit.png \
  --reference assets/headshots/BartBaggett72whitebackgroundB16A5244blue_B.jpg \
  --reference assets/headshots/B16A5236_revised_bart_red_smile.jpg \
  --reference assets/logos/HU_logo_navy_quill.png \
  [--reference $TRAIT_CARD_PATH if provided] \
  --prompt "$(cat /tmp/thumbnail_prompt.txt)" \
  --aspect 9:16 \
  --output outputs/$VID_ID-$SLUG-raw-9x16.png
```

> **Critical:** Do NOT include parchment, text, logo, or headline instructions in the Gemini prompt. Gemini's job is person + environment only. Adding typography or brand elements to the Gemini call causes drift.

### STEP 4 — Run Pass 2: PIL layers the brand elements

```bash
python3 scripts/build_hu_ig_thumbnail.py \
  --input outputs/$VID_ID-$SLUG-raw-16x9.png \
  --headline "$HEADLINE" \
  --subhead "$SUBHEAD" \
  --format 16x9 \
  --output outputs/$VID_ID-$SLUG-final-16x9.png

python3 scripts/build_hu_ig_thumbnail.py \
  --input outputs/$VID_ID-$SLUG-raw-9x16.png \
  --headline "$HEADLINE" \
  --subhead "$SUBHEAD" \
  --format 9x16 \
  --output outputs/$VID_ID-$SLUG-final-9x16.png
```

PIL handles: torn parchment (fractal 3-octave noise), navy collegiate typography (Georgia Bold / Gelasio), HU logo at safe-zone position, drop shadows.

HU color reference:
- Navy: `#1D3557`
- Parchment cream: `#F5F5DC`
- Warm tan emboss: `#BEB696`

### STEP 5 — QA Check before delivery

Before sending to Slack, confirm:
- [ ] Bart's face is recognizable (not a generic AI face)
- [ ] His full head is visible, not cropped
- [ ] Headline text is readable at small size
- [ ] Parchment is cream, not grey or white
- [ ] HU logo is present and not dominant
- [ ] Both 16:9 and 9:16 files exist

If face drift is detected (wrong person generated), do NOT send. Re-run Pass 1 with the same headshot and an adjusted prompt emphasizing likeness. Try up to 2 retries before flagging to Bart.

### STEP 6 — Upload finished files to Google Drive

```
Upload both final PNGs to the HU Thumbnails approval folder in Google Drive.
Capture the shareable URL for each file.
```

Folder: `Handwriting University / Thumbnails / Pending Approval / $VID_ID-$SLUG/`

### STEP 7 — Deliver to Bart via Slack

Send to Bart's Slack DM (or designated thumbnail review channel). Message format:

```
🎬 *Thumbnail ready for approval — $VID_ID: $SLUG*

Headline: "$HEADLINE"
$SUBHEAD (if present)

*16:9 YouTube version:* [link]
*9:16 Reels/TikTok version:* [link]

Reply:
✅ *approve 16:9* — uploads to YouTube
✅ *approve 9:16* — saves for Instagram/TikTok
✅ *approve both*
🔄 *regenerate* — tell me what to change
```

### STEP 8 — On Approval

When Bart replies "approve":
- 16:9 approved → run `yutu thumbnail-set` with the 16:9 file for the YouTube video
- 9:16 approved → move file to the Instagram/TikTok ready folder in Google Drive
- Log the apply date in `youtube-thumbnail-log.md`

When Bart replies "regenerate" + notes:
- Adjust the relevant variable(s) in the prompt
- Re-run from Step 2
- Re-deliver via Slack

## 6. GEMINI PROMPT TEMPLATE (6-SECTION FORMULA)

This is the proven structure from the July 2026 batch. Do not add sections. Do not merge sections. Fill in variables and send as-is.

```
A professional YouTube video thumbnail in 16:9 aspect ratio.

ATTACHED IMAGES:
- Image 1 (headshot): Reference photo of Bart Baggett. Use his exact likeness — fuller face, tousled dark-blonde hair with grey, blue eyes.
- Image 2 (headshot variant): Additional reference for Bart's likeness.
- Image 3 (headshot variant): Additional reference for Bart's likeness.
[- Image 4 (trait card): {VISUAL_LEFT description} — if trait card image provided]

PERSON:
Use the likeness from the headshot images. Place Bart on the RIGHT side of the frame, taking up approximately 40% of the width. Waist-up shot. {EXPRESSION}. Fuller face, tousled dark-blonde hair with grey, blue eyes. Looking slightly LEFT toward the visual element. Dramatic directional lighting on his face.

BACKGROUND:
{BACKGROUND}. Real environmental depth — never a flat void, never solid black. No glow effects. Cinematic and atmospheric.

VISUAL ELEMENTS (left side):
Upper-left: {VISUAL_LEFT}. Large — approximately 40% of frame height. Slightly angled like a specimen card or exhibit. If it is a handwriting sample, add a bold red circle highlighting a key stroke with an annotation arrow pointing to it.

TEXT:
Do not render any text. Typography will be added in post-processing.

STYLE:
High contrast. Cinematic. Dramatic directional lighting. Polished and modern. Maximum 3 visual elements. Keep the lower portion of the frame clean for parchment overlay. Do not add any text, captions, labels, or watermarks.
```

> **Why no text in Gemini:** PIL adds the headline, parchment, and logo in Pass 2 with full brand control. Asking Gemini to render text produces wrong fonts, wrong colors, and unpredictable placement.
